# Near Vote App

서버 없이 근거리 사용자끼리 설문을 만들고 투표 결과 원장을 공유하는 앱의 화면 기반 프로토타입입니다.

`near-vote-ledger`가 한 화면에서 전체 기능을 검증하는 실험판이라면, 이 프로젝트는 실제 앱 구현을 염두에 둔 화면 단위 구조입니다.

## 실행

```sh
python3 -m http.server 4280
```

그다음 브라우저에서 `http://127.0.0.1:4280`을 엽니다.

## 화면 흐름

- 홈: 템플릿과 최근 원장 진입
- 설문 작성: 템플릿 수정, 저장, 근거리 게시
- 진행중인 투표: 현재 게시된 투표의 참여/투표 상태 확인
- 투표: 참여자의 선택지 투표
- 대기: 제한 시간과 투표 수집 상태
- 결과: 최종 블록과 내 투표 포함 여부 확인
- 지난 결과: 로컬에 저장된 결과 블록 목록
