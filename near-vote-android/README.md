# Near Vote Android

주변 기기와 근거리 무선 연결로 실시간 투표를 만들고, 참여하고, 결과를 즉시 공유하는 Android 앱입니다.

서버 없이 가까이 있는 사용자끼리 연결하며, 투표 생성, 투표 참여, 영수증, 결과 공유 흐름을 Android 기기 간 메시지 교환으로 처리합니다.

## 변경 이력

버전별 주요 개선 사항은 [CHANGELOG.md](CHANGELOG.md)에서 확인할 수 있습니다.

## 현재 범위

- Android 프로젝트 골격
- Nearby Connections 권한 선언
- 런타임 권한 요청
- 광고/탐색 시작 버튼
- 연결 요청/수락
- UTF-8 JSON 텍스트 payload 송수신
- Poll/Vote/Receipt/Result/Gossip 메시지 타입 초안
- 한 기기에서 투표/영수증/결과 블록을 확인하는 로컬 시뮬레이션
- 홈, 투표 작성, 주변 투표, 결과, 개발자 진단 화면 분리
- 질문, 선택지, 제한시간을 직접 입력하는 투표 게시 화면
- 제한시간 종료 시 제안자 기기에서 결과 자동 공유
- 같은 참여자 아이디의 중복 투표 방지
- 형용사+사물 형식의 아이디 제안, 저장, 수정
- 공유된 결과와 내 투표 영수증 로컬 저장
- 영수증은 투표한 기기에 직접 전송하고, 제안자 본인 투표는 로컬 영수증으로 저장
- 기본 템플릿 선택, 내 템플릿 저장/삭제
- 결과 블록의 참여자 목록 포함과 결과 해시 재검증
- 투표별 참여자 선택 공개 또는 득표수만 공개 설정
- 실제 투표 참여자에게만 결과 전달
- 앱 재시작 후 진행 중 투표와 참여 상태 복원
- 내부 사용자 ID 교환을 통한 동일 표시 아이디 사용자 구분
- 결과 화면에서 선택지별로 누가 선택했는지 확인
- 결과 생성/공유 시각을 저장하고 지난 결과와 상세 결과에 휴먼프렌들리하게 표시
- 결과 목록과 상세에서 게시자 아바타로 투표 출처 표시
- 하단 탭 메뉴로 홈, 투표, 결과, 설정 주요 화면 이동
- 상단 메뉴 아래 브레드스크럼 경로로 현재 위치 표시
- 모든 화면의 메뉴 영역에 본인을 포함한 참여 가능 인원 배지를 표시하고, 선택 시 연결 상대 목록 팝업 제공
- 앱 실행 후 자동 Nearby 광고/탐색 시작
- 10초 주기 주변 연결 유지와 참여 가능 인원 표시
- 연결된 기기 수와 가능한 경우 상대 기기 이름 표시
- 같은 상대 기기가 중복 endpoint로 연결될 때 유니크 기기 기준으로 정리
- 새 기기 연결 시 진행 중인 투표 또는 공유 결과 자동 전달
- 화면 표시 아이디와 내부 고유 사용자 ID 분리
- 설정 화면에서 자동 연결 켜기/끄기 관리
- 홈에서 게시 중인 투표, 받은 투표, 최근 결과를 현재 세션 카드로 표시
- 진행 중인 세션, 받은 투표, 지난 결과가 없을 때 다음 행동을 안내하는 빈 상태 화면
- 투표 작성에서 빠른 선택과 확장 휠로 10초부터 8시간까지 제한시간 설정
- 액션 카드, 선택 버튼, 결과 막대의 시각 계층과 터치 영역 개선
- 자동 재전송으로 같은 투표/결과를 다시 받아도 화면 반복 전환 방지

## 한 기기 테스트

안드로이드 기기가 1대뿐이면 `로컬 시뮬레이션 실행`을 눌러 개발을 이어갑니다.
이 모드는 가상 참여자 3명을 만들고 투표 생성, 투표, 영수증, 결과 블록 로그를 한 번에 보여줍니다.
실제 무선 연결 검증은 아니지만, 두 번째 기기를 확보하기 전까지 앱 흐름과 원장 메시지 구조를 다듬는 데 사용합니다.

## 두 기기 연결 테스트

1. 두 Android 기기에 같은 APK를 설치합니다.
2. 두 기기 모두 Bluetooth, Wi-Fi, 위치를 켭니다.
3. 앱 권한 요청을 모두 허용합니다.
4. 하단 접속 배지에 본인을 포함한 참여 가능 인원 `2`가 표시되고, 팝업에 연결 상대 이름이 보이는지 확인합니다.
5. 필요하면 `개발자 진단`에서 `테스트 메시지 보내기`를 누릅니다.
6. 반대쪽 로그에 메시지 수신 기록이 보이면 Nearby 통신이 확인된 것입니다.

## 투표 게시와 참여 테스트

1. 두 기기에서 앱을 실행하고 접속 배지가 참여 가능 인원 `2`로 바뀌는지 확인합니다.
2. 제안자 기기에서 `투표 만들기`로 질문, 선택지, 제한시간을 입력합니다.
   - 제한시간과 결과에서 참여자별 선택을 공개할지 여부를 함께 설정합니다.
3. 제안자 기기에서 `게시하기`를 누릅니다.
4. 참여자 기기에서 참여 요청을 수락한 뒤 선택지를 누릅니다.
5. 참여자 기기에 투표 영수증이 표시되는지 확인합니다.
6. 제안자 기기의 `게시한 투표` 화면에서 집계가 갱신되는지 확인합니다.
7. 제안자 기기에서도 선택지를 눌러 본인 투표가 집계되고 영수증이 저장되는지 확인합니다.
8. 같은 참여자가 다시 선택할 수 없는지 확인합니다.
9. 제안자 기기에서 `투표 종료`를 누르거나 제한시간 종료 후 투표한 참여자에게 결과가 공유되는지 확인합니다.
10. 선택 내역 공개 투표인 경우 결과 화면에서 각 선택지에 어떤 참여자가 있는지 확인합니다.
11. 중간에 새 기기가 연결되면 진행 중인 투표나 공유 결과가 자동으로 전달되는지 확인합니다.

## 화면 흐름

- 홈: 내 아이디, 게시 중/받은 투표, 최근 투표
- 하단 탭: 홈, 투표, 결과, 설정, 참여 가능 인원 배지
- 내 아이디: 제안 아이디 사용, 새 아이디 제안, 직접 수정
- 설정: 자동 연결 켜기/끄기, 내 아이디 관리
- 투표 작성: 직접 입력, 템플릿 선택, 공개 범위와 제한시간 설정 후 게시
- 진행 중인 투표: 수신한 참여 요청과 투표 참여
- 시뮬레이션 결과: 참여자, 선택지, 결과, 영수증/해시 요약
- 지난 결과: 저장된 결과 블록, 참여자 목록, 무결성 확인, 내 투표 영수증 확인
- 개발자 진단: 광고, 탐색, PING, 상세 로그

홈과 주요 화면은 사용자 행동 중심 카드로 구성하고, Nearby 광고/탐색/PING 같은 개발용 기능은 개발자 진단 화면에만 둡니다.

## 코드 구조

- `MainActivity.kt`: 화면 구성과 사용자 흐름
- `data/NearVoteModels.kt`: 투표, 영수증, 결과 모델과 JSON 변환
- `data/NearVoteStore.kt`: 아이디, 영수증, 지난 결과 로컬 저장
- `nearby/NearbyVoteConnectionManager.kt`: Nearby Connections 광고, 탐색, 메시지 송수신
- `protocol/NearVoteMessage.kt`: 네트워크 메시지 envelope
