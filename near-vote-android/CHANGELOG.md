# 변경 이력

Near Vote Android의 사용자에게 의미 있는 기능 변화와 개선 사항을 버전별로 기록합니다.

## v0.3.0 - 2026-05-25

### 주요 변경사항

- 연결된 사용자를 표시 아이디가 아닌 내부 고유 ID로 식별하도록 프로필 교환 흐름을 추가했습니다.
- 내 아이디 또는 아바타를 수정해도 진행 중 투표와 참여 상태가 유지되도록 개선했습니다.
- 앱을 재시작해도 진행 중 투표, 받은 투표, 수락/거절과 결과 공유 상태를 복원합니다.
- 투표 ID를 UUID 기반으로 변경하고, 영수증과 결과 블록 수신 시 무결성 확인을 강화했습니다.
- 결과 공유를 실제 투표 참여자에게 제한하고, 선택 내역 공개 여부를 투표별로 설정할 수 있게 했습니다.
- 접속 현황 배지는 본인을 포함한 참여 가능 인원으로 표시하고, 연결된 상대 수와 구분해 안내합니다.
- 연결 직후 내부 사용자 ID 확인이 끝나기 전에는 접속 현황 숫자와 투표 전송 대상에 반영하지 않도록 보완했습니다.
- 홈 이외 화면의 상단 제목 영역에 내 아바타 바로가기를 추가해 아이디 관리로 빠르게 이동할 수 있습니다.
- 상단 아바타에 프로필 액자 테두리와 배경을 적용해 진입 버튼임을 분명히 했습니다.
- 결과 상세 화면 제목을 `투표 결과`로 통일하고 질문 카드의 중복 분류 라벨을 제거했습니다.
- `N`과 체크 형태의 `V`를 결합한 Near Vote 런처 아이콘을 적용했습니다.
- 핵심 결과 및 공개 범위 직렬화 동작에 대한 단위 테스트를 추가했습니다.

## v0.2.0 - 2026-05-25

### 주요 변경사항

- 하단 내비게이션을 탭 바 형태로 정리하고 홈 화면의 중복 동선을 제거했습니다.
- 내 아이디에 선택할 수 있는 기본 아바타 20종을 추가하고, 투표 결과와 참여자 표시에도 아바타를 반영했습니다.
- 주변 연결 수를 최대 20대로 제한하고, 자동 연결 유지 확인을 10초 주기로 개선했습니다.
- 접속 현황 배지에 주변 탐색 활동을 알리는 파장 효과를 추가했습니다.
- 앱 재시작 시 자동 연결 세션을 초기화하고 다시 시작하도록 보완했습니다.
- 제한시간 확장 휠을 추가해 10초부터 8시간까지 단계별로 선택할 수 있게 했습니다.
- 투표 원형 타이머를 남은 시간 길이에 따라 `초`, `분:초`, `시:분:초` 형식으로 표시하도록 개선했습니다.
- 투표 작성 화면에서 선택지를 태그 형태로 추가, 선택, 수정, 삭제할 수 있게 했습니다.
- 투표별로 참여자의 새 선택지 입력을 허용하고, 입력한 선택지에 바로 투표할 수 있게 했습니다.
- 새 선택지 입력 시 키보드의 실제 높이만큼 스크롤 공간을 확보해 입력 영역이 가려지지 않도록 보완했습니다.
- 결과를 득표순으로 표시하고 지난 결과에 1위 선택지를 요약하도록 개선했습니다.
- 홈에서 내 아이디 편집 화면으로 바로 이동하고 아이디 동작 버튼 배치를 정리했습니다.
- 결과 목록과 상세 화면의 메타 정보, 참여자 태그, 최근 투표 표시를 정리했습니다.
- 결과 화면에서 같은 내용으로 재투표하거나 템플릿으로 저장할 수 있는 아이콘 액션을 추가했습니다.
- 짧은 남은 시간은 붉은 색으로 강조하고, 접속자 수 배지 숫자 전환 애니메이션을 개선했습니다.
- 상단 및 하단 시스템 영역과 겹치지 않도록 화면 레이아웃을 보완했습니다.
- 생성되는 APK 파일명을 `NearVoteAndroid.apk`로 통일했습니다.

## v0.0.1 - 2026-05-24

### 초기 버전

- 서버 없이 Nearby Connections로 주변 Android 기기를 탐색하고 연결하는 기본 구조를 만들었습니다.
- 투표 생성, 참여, 영수증 전달, 결과 공유와 결과 검증 흐름을 구현했습니다.
- 투표 참여 요청 수락/거절과 거절 사용자의 결과 수신 제외 처리를 추가했습니다.
- 기본 템플릿과 내 템플릿 관리, 결과 기록, 내부 고유 사용자 ID 저장을 마련했습니다.
- 홈, 투표, 결과, 설정, 개발자 진단 화면과 자동 연결 설정을 구성했습니다.
- Android 시스템 내비게이션 영역과 앱 하단 메뉴가 겹치지 않도록 처리했습니다.
